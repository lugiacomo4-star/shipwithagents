The setup, in five steps

  1. One folder of facts

    Plain Markdown files, one per subject: people/, projects/, topics/. One fact per line. Any agent can read a text file, so nothing gets locked into one app.

  2. One door every agent can reach

    A single shared page (I use Notion) where any agent appends a line in the same format. Agents that can't touch your disk still get in this way.

    2026-11-03 · grok · work · Prefers HR and operations roles 2026-11-03 · hermes · tools · Runs on the Mac mini, reads ~/.hermes/memories

  3. One rule in every agent's instructions

    Paste the rule below into each agent's system prompt or project instructions. Same words for all of them.

  4. A sync that signs every line

    Every 6 hours a small job reads the door, drops bad lines (incomplete, or with card numbers, IBANs or passwords) and files each fact with the agent's name on it.

  5. A map that shows who wrote what

    Every file is a star, every link between files is a line, and the color is the author. The first time you look, you'll see which agent is pulling its weight.

The rule, copy it as is
MEMORY RULE
When you learn something durable about me (a decision, a preference,
a person, a deadline), write ONE line to the shared memory page:
YYYY-MM-DD · your-name · topic · the fact
- One fact per line. No guesses, only what I said or confirmed.
- Never write passwords, card numbers, IBANs or ID numbers.
- Before answering anything about me, read the memory first.
